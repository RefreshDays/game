# ✅ 할로윈 사탕 미로 — 확인 사항 체크리스트

개발 정의서: [halloween-maze-개발정의서.md](halloween-maze-개발정의서.md)

## A. 아이(기획자)에게 물어볼 것 — 기획 의도 확인

### 1차 피드백으로 정해진 것 ✔
- [x] 사탕을 **전부** 모아야 출구가 열린다
- [x] 출구는 처음에 안 보이고, 돌아다니다 불빛으로 비춰서 **찾아야** 한다
- [x] 캐릭터 주변만 밝고 나머지는 **완전히 까맣게**
- [x] 유령에게 잡히면 하트 1개 잃고 **사탕 리셋 + 처음 자리로**
- [x] 유령은 더 늦게 나오고, 더 느리고, **왔다 갔다 하며 겁주기** (길을 너무 잘 찾지 않게)
- [x] **5판 깨면 엔딩**, 그 뒤 무한 모드

### 2차로 물어볼 것
- [ ] 잡혔을 때 **이미 찾은 출구도 다시 숨겨지는데** 괜찮은지? (지금은 "완전히 처음으로" — 출구 위치는 기억하게 할 수도 있음)
- [ ] 출구는 한 번 찾으면 계속 보이는데 괜찮은지?
- [ ] 어둠 속 **유령 빨간 눈**은 계속 보이게 둘지, 눈도 안 보이게 할지?
- [ ] 유령 무서움 정도: 레벨 1에서 가만히 있으면 40초 넘게 안 잡힐 정도로 느슨해짐. 너무 쉬우면 `ghostSense`(알아채는 거리)나 속도를 올리면 됨
- [ ] 엔딩까지 **5판**이 적당한지 (3판? 10판?)
- [ ] 엔딩 문구: "유령들이 '다음 할로윈에 또 보자~' 하고 사라졌어요" — 아이가 직접 쓰고 싶은지?
- [ ] 주인공 모양 (노란 머리 블록 소년 + 호박색 옷), 하트 3개, 게임 제목 "할로윈 사탕 미로" 괜찮은지

### 3차 (배경음악·제한시간·랭킹) 확인
- [ ] 배경음악이 "긴장되고 귀여운" 느낌인지, 너무 시끄럽거나 반복이 지루하지 않은지
- [ ] 유령이 쫓아오거나 15초 남았을 때 음악이 빨라지는 게 좋은지
- [ ] 제한시간이 적당한지 (레벨 1 약 1:20~2:00) — 짧으면 `timeFactor`/`timeExtra`를 늘리면 됨
- [ ] 시간 초과 때 바로 게임 오버가 맞는지, 하트 1개만 잃게 할지
- [ ] 잡혀서 처음으로 돌아가도 시간이 계속 흐르는 게 맞는지
- [ ] 점수 규칙 (사탕 100, 탈출 레벨×300, 남은 1초당 5, 하트 100) 괜찮은지
- [ ] 친구들이 **한 휴대폰을 돌려 가며** 할지, **각자 휴대폰**으로 할지 → 각자면 온라인 랭킹 설정(개발정의서 3-1) 필요
- [ ] 랭킹에 실명 대신 별명 쓰기

### 4차 (협동 모드) 확인
- [ ] 잡히면 그 친구만 처음 자리로, **팀 하트 -1**, 모은 사탕은 그대로 — 혼자 할 때처럼 사탕도 리셋할지?
- [ ] 팀 하트 3개가 적당한지 (사람 수만큼 늘릴지)
- [ ] **한 명이라도** 출구에 들어가면 모두 탈출 — 모두 다 들어가야 탈출로 할지?
- [ ] 다음 레벨 자동 시작(4초)이 좋은지, 모두 "준비" 누르면 시작할지
- [ ] 실제 휴대폰 2~4대로: 친구 움직임이 부드럽게 보이는지, 유령이 끊기지 않는지

## B. 실제 휴대폰에서 직접 해보고 확인할 것

- [ ] 아이폰 Safari에서 열림 / 안드로이드 Chrome에서 열림
- [ ] 세로 화면에서 미로와 십자 버튼이 한 화면에 다 들어옴
- [ ] 가로로 돌렸을 때 버튼이 오른쪽에 잘 나옴
- [ ] 십자 버튼이 아이 손가락에 충분히 큰지 (누른 채로 미끄러져 방향 바꾸기 되는지)
- [ ] 화면 스와이프로도 이동되는지 (원치 않으면 끌 수 있음)
- [ ] 버튼 누르다가 화면이 확대되거나 스크롤되지 않는지
- [ ] 소리가 나는지 (아이폰은 **무음 스위치**가 켜져 있으면 소리 안 남), 🎵 버튼으로 음악+효과음 → 효과음만 → 끄기가 되는지
- [ ] 배경음악이 끊기거나 늦게 나오지 않는지 (오래된 폰)
- [ ] 이름 입력칸을 누르면 키보드가 잘 올라오는지
- [ ] 유령에게 잡힐 때 진동 (안드로이드만 지원, 아이폰은 미지원 — 정상)
- [ ] 다른 앱 갔다 오면 일시정지 되어 있는지
- [ ] 미로 칸이 너무 작아 보이지 않는지 (레벨이 높으면 칸이 작아짐 — 작은 폰에서 레벨 6~8 확인)
- [ ] 노치/홈 바에 HUD나 버튼이 가리지 않는지
- [ ] 홈 화면에 추가 후 실행 시 정상

## 휴대폰에서 빈 화면(가운데 빈 보라색 막대)만 나올 때

원인: 게임 파일을 **파일 보기 앱**(내 파일, 메신저 미리보기 등)으로 열면 화면 모양만 보이고 게임 코드(JavaScript)는 실행되지 않음. 딸 폰 화면이 정확히 이 상태였음 (같은 증상을 재현해서 확인).

해결:
- [ ] 받은 파일은 **길게 누르기 → 다른 앱으로 열기 → Chrome / 삼성 인터넷**으로 열기
- [ ] 예전에 받은 파일은 지우고 **최신 파일**로 다시 받기 (옛날 파일에는 제한시간·랭킹이 없음)
- [ ] 가장 좋은 방법: 파일 대신 **인터넷 주소(링크)**로 열기 → GitHub Pages 켜기 (D 항목)
- v3.1부터는 이 상황에서 빈 막대 대신 "크롬이나 삼성 인터넷으로 열어 주세요" 안내가 나오고, 다른 오류가 나면 오류 내용이 화면에 보임
