# 🎃 할로윈 사탕 미로 — 개발 정의서

> 아이가 음성으로 기획한 내용을 바탕으로 만든 모바일용 2D 레고 스타일 미로 게임.
> 실행 파일: [`halloween-maze/index.html`](../halloween-maze/index.html) (파일 1개, 설치 필요 없음)

---

## 1. 원본 기획

아이가 음성으로 기획한 아이디어를 바탕으로 만들었습니다 (원본 녹음·받아쓰기는 비공개 저장소에 보관).

### 기획 요소 → 구현 매핑

| 아이 아이디어 | 게임에 구현된 내용 |
|---|---|
| 미로 안의 사람(소년) 말 | 노란 머리 블록 피규어 소년 (호박색 옷) |
| 방향키 위/아래/왼/오 | 키보드 방향키·WASD + **모바일 십자 버튼** + 스와이프 |
| 미로를 탈출하면서 사탕 찾기 | 사탕을 모두 모으면 출구 문이 열림 → 출구 도착 시 탈출 성공 |
| 소년 주변만 동그랗게 불빛 | 소년 중심 원형 조명, 나머지는 완전히 까맣게 (불빛이 살짝 일렁임) |
| 미로는 안 보이고 사탕 위치는 보임 | 벽은 어둠 속에 가려지고, 사탕은 어둠 위에서 반짝이며 항상 보임 |
| 미로를 따라 유령이 쫓아옴 | 유령이 벽을 통과하지 않고 길을 따라 왔다 갔다 떠돌다가, 가까워지면 쫓아옴 |

## 2. 게임 개요

| 항목 | 내용 |
|---|---|
| 제목 | 할로윈 사탕 미로 |
| 장르 | 2D 탑다운 미로 탐험 / 수집 / 추격 피하기 |
| 대상 | 초등 저학년 아이 (짧은 판, 쉬운 조작) |

| 컨셉 | 할로윈: 보라·주황·검정·초록 색감, 사탕, 유령, 호박, 잠긴 문 |

## 3. 게임 규칙 (아이 피드백 반영 v2)

1. 소년은 미로 왼쪽 위에서 출발한다.
2. 화면은 **완전히 까맣고**, 소년 주변만 원형으로 밝다. 벽은 불빛 안에서만 보인다.
3. **사탕 🍬은 어둠 속에서도 반짝여서 위치가 보인다.**
4. **출구 🚪는 처음엔 보이지 않는다.** 돌아다니다가 불빛으로 비추면 발견되고, 그때부터 표시된다.
5. 출구는 잠겨 있다. **사탕을 전부 모아야** 열린다. 잠긴 출구에 서면 "사탕을 다 모아야 열려요 (n/전체)" 안내가 나온다.
6. **유령 👻**은 레벨 1 기준 **8초 뒤**에 나타나고, 다음 유령은 6초 간격으로 나온다. 어둠 속에서는 **빨간 눈**만 보인다.
7. 유령은 소년이 멀리 있으면 **왔다 갔다 떠돌며** (갑자기 뒤돌기, 멈춰서 두리번거리기) 겁을 주고, 길 따라 가까이(레벨 1은 5칸 이내) 오면 그때 쫓아온다. 쫓을 때도 가끔 길을 헷갈린다.
8. 유령에게 잡히면 **하트 1개를 잃고, 모은 사탕은 모두 원래 자리로 돌아가고, 출구도 다시 숨겨지고 잠기며, 처음 자리로 돌아간다.** (2초 무적)
9. 하트 3개를 모두 잃으면 게임 오버 → 같은 레벨 다시 도전.
10. **10판을 모두 탈출하면 엔딩 화면** 🏆 (모은 사탕 수, 걸린 시간). 이후 "무한 모드"로 레벨 6, 7, … 계속 도전 가능.

### 레벨 난이도 곡선 (코드 `CFG` 에서 조절)

| 레벨 | 미로 칸 수(대략) | 사탕 | 유령 | 첫 유령 등장 | 유령 속도(칸/초) | 유령이 알아채는 거리 | 불빛 반경(칸) |
|---|---|---|---|---|---|---|---|
| 1 | 40 | 3 | 1 | 8초 | 1.5 | 5칸 | 3.3 |
| 2 | 50 | 4 | 1 | 7초 | 1.75 | 6칸 | 3.2 |
| 3 | 60 | 5 | 2 | 6초 | 2.0 | 7칸 | 3.0 |
| 4 | 70 | 6 | 2 | 5초 | 2.25 | 8칸 | 2.9 |
| 5 (마지막) | 80 | 7 | 3 | 4초 | 2.5 | 9칸 | 2.8 |
| 무한 6+ | 90+ | 8~10 | 3~4 | 4초 | 2.75~3.6 | 10칸 | 2.7 이하 |

소년 속도: 5.2칸/초 (유령보다 항상 2배 이상 빠름). 떠도는 유령은 위 속도의 75%로 움직인다. 미로는 매번 무작위로 생성되며, 막다른 길만 있으면 유령을 피할 수 없으므로 순환 통로를 일부 뚫어 둔다.

## 3-1. 배경음악 · 제한시간 · 점수 · 랭킹 (v3)

### 🎵 배경음악
- 파일 없이 WebAudio로 직접 연주: 가단조의 통통 튀는 베이스 + 실로폰 같은 멜로디 + "똑딱" 소리 → **귀엽지만 으스스**
- **긴장 모드**: 유령이 쫓아오기 시작하거나 남은 시간이 15초 이하가 되면 템포가 108 → 148로 빨라지고 떨리는 높은 음이 더해짐
- 🎵 버튼을 누를 때마다 **음악+효과음 → 효과음만 → 끄기** 순서로 바뀜 (설정 저장)
- 게임 중에만 재생, 일시정지·결과 화면에서는 멈춤

### ⏱ 단계별 제한시간
- 미로마다 다르게 자동 계산: `(사탕을 가까운 순서로 다 먹고 출구까지 가는 최단 길이 ÷ 소년 속도) × 6 + 40초`, 10초 단위 올림
- 실제 값 예시: 레벨 1 약 1:20~2:00, 레벨 3 약 2:00~2:50, 레벨 5 약 2:20~3:40
- 유령에게 잡혀 처음으로 돌아가도 **시간은 계속 흐름**
- 남은 시간 15초부터 HUD 시계가 빨갛게 깜빡이고 1초마다 "똑" 소리, 5초부터는 더 높은 소리, 안드로이드는 시간 초과 때 진동
- **시간 초과 = 게임 오버** (같은 레벨부터 다시 도전 가능)

### ⭐ 점수 (레벨 탈출할 때마다 더함)
| 항목 | 점수 |
|---|---|
| 모은 사탕 | 1개당 100 |
| 레벨 탈출 | 레벨 × 300 |
| 남은 시간 | 1초당 5 |
| 남은 하트 | 1개당 100 |

게임이 끝날 때(유령·시간 초과로 게임 오버, 5판 엔딩, 일시정지 후 처음 화면으로 나가기) 점수가 랭킹에 기록됨. "다시 하기"는 새 판(점수 0)으로 시작.

### 🏆 랭킹
- 시작 전 **이름 입력** (최대 8글자, 다음에도 기억). 이름별 **최고 점수**만 남김
- **📱 이 기기 랭킹**: 친구들이 한 휴대폰을 돌려 가며 하면 바로 순위 경쟁 가능 (설정 필요 없음)
- **🌐 친구들 랭킹(온라인)**: 친구들이 각자 휴대폰에서 해도 같은 순위표를 보려면 아래 설정 필요
- 결과 화면에 "새 최고 기록! 이 기기 랭킹 n등 · 친구 랭킹 n등" 표시

### 🌐 온라인 랭킹 설정 (부모님, 약 10분, 무료)
Claude 아티팩트 링크에서는 외부 서버 연결이 막혀 있고, 아티팩트 자체 저장소는 claude.ai 계정이 있고 편집자로 초대된 사람만 쓸 수 있어서 아이 친구들에게는 맞지 않습니다. 그래서 **GitHub Pages + Firebase(무료)** 방식을 씁니다.

1. https://console.firebase.google.com → 프로젝트 만들기 (애널리틱스 끄기)
2. 빌드 → **Firestore Database** → 데이터베이스 만들기 (위치: asia-northeast3 서울, 프로덕션 모드)
3. Firestore → **규칙** 탭에 아래 내용을 붙여 넣고 게시:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{db}/documents {
       match /halloween_scores/{name} {
         allow read: if true;
         allow write: if request.resource.data.keys().hasOnly(['name','score','level','at'])
           && request.resource.data.name == name
           && request.resource.data.name is string && request.resource.data.name.size() <= 8
           && request.resource.data.score is int && request.resource.data.score >= 0 && request.resource.data.score < 200000
           && request.resource.data.level is int && request.resource.data.level <= 100
           && (resource == null || request.resource.data.score > resource.data.score);
       }
     }
   }
   ```
4. 프로젝트 설정(톱니바퀴) → 일반 → **웹 앱 추가** → 나오는 `projectId`, `apiKey` 두 값을 복사
5. (완료) `halloween-maze/index.html` 안의 `const ONLINE = { projectId: '', apiKey: '' ...` 에 붙여 넣기 (또는 Claude에게 값을 알려 주면 넣어 드림)
6. GitHub 저장소 Settings → Pages 켜기 → `https://refreshdays.github.io/game/halloween-maze/` 주소를 친구들에게 공유

주의: 이름만으로 기록하는 간단한 방식이라 같은 이름을 쓰면 같은 칸으로 합쳐지고, 마음먹으면 점수를 조작할 수 있습니다 (규칙으로 비정상 값·점수 낮추기는 막음). 실명 대신 **별명** 사용을 권장합니다. apiKey는 웹 앱용 공개 값이라 노출돼도 괜찮습니다 (보안은 위 규칙이 담당).

## 4. 조작 (모바일 최우선)

| 입력 | 동작 |

- 유령에게 잡히면 진동 (안드로이드 지원 기기)

## 5. 화면 구성

1. **타이틀**: 게임 설명, 조작법, 최고 기록, 이름 입력, [시작하기] [🏆 랭킹 보기]
2. **플레이**: HUD(🎃 레벨, 🍬 모은 사탕/전체, ❤️ 하트, ⏱ 남은 시간, 🎵, ⏸) + 미로 + 십자 버튼 + 안내 메시지(토스트)
3. **일시정지**: [계속하기] [처음 화면]
4. **탈출 성공**: 걸린 시간, 점수 내역(사탕/탈출/남은 시간/하트), 누적 점수, [다음 레벨] [처음 화면]
7. **게임 오버** (유령 / ⏰ 시간 초과): 점수, 랭킹 순위, [다시 하기] [🏆 랭킹 보기] [처음 화면]
8. **랭킹**: [📱 이 기기] [🌐 친구들] 탭, 상위 30명

## 6. 기술 구조

```
halloween-maze/index.html
 ├─ CFG            난이도/속도/개수 설정값 (여기만 고치면 밸런스 조절)
 ├─ genMaze()      재귀 백트래킹 미로 생성 + 순환로 추가
 ├─ bfs()          거리 지도: 출구 위치(가장 먼 칸), 유령 추적 경로
 ├─ setupLevel()   미로 크기를 화면 비율에 맞춰 생성, 사탕/유령/출구 배치
 ├─ 입력           키보드, 십자패드(pointer events), 스와이프
 ├─ update()       칸 단위 부드러운 이동, 사탕 획득, 유령 AI, 충돌
 ├─ render()       정적 레이어(벽/바닥, 미리 그려 둠) → 캐릭터 → 어둠 마스크(원형 구멍) → 사탕/출구/유령 눈
 ├─ SFX            WebAudio로 만든 효과음 (파일 없음)
 └─ localStorage   최고 레벨, 소리 설정 저장
```

- 그림은 모두 Canvas 도형으로 그림 (이미지 파일 0개) → 저작권 걱정 없음, 로딩 즉시
- 고해상도 화면 대응 (devicePixelRatio 최대 2배)
- 테스트용 훅: `window.__game` (상태 조회)
